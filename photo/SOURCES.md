# Фотоатлас: фотографии, источники и лицензии

В наборе 8 планет, 22 основных спутника и все 110 объектов Мессье. Ни один объект не представлен художественным рендером.

Снимки NASA, ESA, ESO, NOIRLab, 2MASS и авторов Wikimedia Commons. Условия для каждого файла приведены ниже. Некоторые снимки составлены из наблюдений в нескольких фильтрах, сняты вне видимого диапазона или имеют усиленный цвет. Эти пояснения отображаются в карточках.

## Изменения для игры

Фотографии скачаны и уменьшены с сохранением пропорций; часть файлов перекодирована в JPEG и сжата. Новые детали не дорисовывались, фотографии разных объектов не подменялись. Кадры показываются целиком с полями, без дополнительного обрезания интерфейсом. Для уменьшенных копий сохраняется лицензия исходного файла, включая ShareAlike там, где она предусмотрена.

Код игры распространяется по MIT; это не меняет лицензии и права на изображения. Факты в карточках пересказаны по указанным источникам.
