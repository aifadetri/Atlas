# Эклиптика — тренажёр дат 13 созвездий

Отдельный ресурс проекта «Атлас»: https://aifadetri.github.io/Atlas/zodiac/

Светлая кремовая, тёмно-зелёная и терракотовая палитра. Без регистрации, почты, рейтинга и серверных запросов.

## Главная и два режима

- Главная: таблица входа и выхода Солнца для всех 13 созвездий эклиптики, включая Змееносца.
- «Назвать обе даты»: ввод даты входа и даты выхода; ответ верен только при совпадении обеих. При частичном ответе отдельно подсвечены верное и неверное поля.
- «Узнать по дате»: одна дата и выбор из 13 созвездий. Дни перехода между созвездиями не используются.

Поддерживаются циклы 2025–2026 … 2029–2030, по умолчанию 2026–2027. Цикл идёт от январского входа Солнца в Козерог до следующего входа в Козерог, поэтому Стрелец представлен одним цельным интервалом через Новый год.

## Астрономическая основа

Положение видимого геоцентрического центра Солнца вычислено по JPL DE421 в Skyfield 1.55 и сопоставлено с официальными областями IAU. Даты в UTC. Вход и выход — реальные расчётные моменты пересечения границы; в таблице указаны даты и приблизительное время до минут. Эти даты зависят от года.

Дата выхода одного созвездия совпадает с датой входа следующего. В вопросах по одной дате такие сутки исключены, чтобы не требовать время суток. Время вводить в упражнении на границы не нужно. Источники, метод и воспроизводимый расчёт: SOURCES.md и research/.

## Прогресс и работа без интернета

Личные числа верных/всех ответов, точность и ошибки хранятся в браузере отдельно для каждого режима и цикла. Повторение ошибки снимается после правильного ответа. Сброс серии не удаляет накопленный прогресс. Очистка данных браузера удаляет его; на другом устройстве будет отдельный прогресс.

Ввод: 20.01, 20/01 или «20 января». Проверяются реальные календарные даты и високосный год. Enter после разобранного ответа открывает следующее задание.

Для локального запуска сохраните zodiac/, fonts/, fonts.css и resource-nav.css рядом, затем откройте zodiac/index.html. Все даты уже включены в data.js, вычислительные библиотеки не нужны. Для пересчёта отдельно требуется Python и Skyfield; 17-МБ эфемерида в игру не включена.
