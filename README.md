# Атлас — мастерская созвездий

Учебная игра по астрономии на русском языке.

**Играть: https://aifadetri.github.io/Atlas/**

## Возможности

- Все 88 созвездий, включая 13 зодиакальных со Змееносцем.
- Обучающие карточки с фактами, источниками, яркими звёздами и их видимыми величинами.
- Тренировка с повторением ошибок и игра на время или на результат.
- Наборы: зодиакальные, северные, южные, у экватора, на эклиптике, все созвездия.
- Рисунки с соединительными линиями или только точки.
- Таблица лучших партий с отметкой «С линиями» / «Без линий».
- Статистика по нику: история, точность, результаты по каждому созвездию и индивидуальное повторение.

Рейтинг и статистика хранятся в Supabase и доступны с разных устройств. Прогресс карточек остаётся локальным. Каждый аккаунт имеет отдельный профиль, даже если ники совпадают. Гостевой аккаунт доступен из текущего браузера; для одного аккаунта на нескольких устройствах используется вход по ссылке на почту. Кнопки очистки рейтинга нет. Старые локальные партии автоматически не переносятся.

## Запуск и публикация

Откройте index.html из полной папки или запустите `python3 -m http.server 8765`. Для GitHub Pages публикуется корень ветки main. Сборка не требуется. Все шрифты, звёздные данные и SDK Supabase находятся в репозитории. Для общего рейтинга необходим интернет.

Правильный ответ: +10 баллов. «Стоит повторить»: точность ниже 60%. «Хорошо узнаёшь»: от 80% после минимум трёх ответов. Статистика учитывает завершённые игры; тренировки и прерванные партии в неё не входят. Старые партии без сохранённых отдельных ответов доступны только в истории.

Северные и южные наборы отбираются по опорной точке звёздного рисунка; экваториальные — по пересечению области созвездия небесным экватором. Это учебные фильтры, а не расчёт видимости для города и даты. Соединительные линии — условная схема, а не официальные границы. Величины каталоговые, приблизительные; для тесных кратных систем указана яркость выбранного компонента.

## Supabase

Публичные URL и publishable key находятся в supabase/config.js. Секретные ключи не нужны и не должны попадать в клиентский код. Схема базы: supabase/schema.sql. Включите Anonymous sign-ins, задайте Site URL и Redirect URLs https://aifadetri.github.io/Atlas/. Для отправки ссылок всем ученикам требуется собственный SMTP: стандартный отправитель Supabase ограничен участниками команды проекта.

База проверяет владельца партии, набор, число ответов и сама считает баллы. Клиент не может удалять или напрямую изменять чужие результаты. Это учебный рейтинг, а не защита от намеренной подмены прохождения вопросов. Неудачно отправленные партии остаются в локальной очереди; их можно повторно отправить из профиля.
